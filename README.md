# 动作快速调整器 Demo

这是独立 EXE 方向的第一版 Web MVP 原型，先验证交互和界面逻辑，不改 Godot 游戏场景。

## 运行

在项目根目录启动一个本地静态服务器：

```powershell
python -m http.server 8780
```

也可以直接双击：

```text
start_demo.bat
```

然后打开：

```text
http://localhost:8780/index.html
```

## 验证

```powershell
npm run check
npm run validate:import
```

`validate:import` 会验证两条路径：

- 直接从 `C:\Users\bodean\Downloads\stylized+3d+character+model.glb` 走文件导入。
- 从 `sample_models/stylized_3d_character_model.glb` 走“加载测试模型”按钮。

## 当前范围

- 中文单页界面，左侧模型/骨架，右侧参数调整窗口。
- 可调透明度：右侧提供人物透明度和骨骼透明度滑杆，骨骼透明度同时控制移动箭头、旋转环和辅助控制圈。
- 骨架搭建 Edit 模式：左键点选关节，按住拖远才生成子骨骼，避免误选时拉出长骨骼。
- 姿势调整 Pose 模式：拖动骨骼只旋转，不改变骨长；导入的蒙皮人物会跟随真实骨骼运动。
- Pose 模式关节 `G`：默认固定骨长 IK 移动，拖动中间关节时真实 GLB 骨骼旋转并驱动模型跟随，骨骼长度不会被拉伸；右侧可打开“允许 G 拉长骨骼”作为显式比例编辑模式。
- Blender 风格变换控件：顶部提供 `移动 G`、`旋转 R`、`缩放 S` 和 `局部/世界`。
- 视图内变换手柄：移动箭头、旋转角度环、缩放手柄。
- 视图导航：中键/右键/Alt+左键拖动旋转视图，Shift+中键/右键平移视图，滚轮缩放；左键保留给选择和变换确认。
- 世界坐标辅助：地面原点显示红 X、绿 Y、蓝 Z 三轴。
- Blender 风格快捷键：`Tab` 切换 Edit/Pose，`G` 直接进入移动，`R` 直接进入旋转，`S` 直接进入缩放。
- Modal 操作：按 `G/R/S` 后移动鼠标即可变换，`左键/Enter` 确认，`右键/Esc` 取消，`X/Y/Z` 锁定轴；`R` 按鼠标绕选中点的屏幕角度旋转。
- 撤销：`Ctrl+Z` / `Cmd+Z` 回退骨架、姿势和关键帧编辑。
- 人形骨架模板、分支镜像、骨骼删除、颜色和名称调整。
- 半透明模型参考、准确地面网格、脚底接触点、重心线。
- GLB 导入进度反馈，导入后自动读取 SkinnedMesh 骨骼并显示干净的主骨架，隐藏 Twist 等技术辅助骨。
- 骨骼节点使用细小方块控制点和方向箭头，不再使用球形节点；视觉骨骼更细，拾取区域保留较宽以便点击。
- 权重笔刷视觉 demo：增加、减少、平滑，红色高权重、蓝色低权重；末端关节例如 `R_Foot` 会显示脚掌权重，不再误显示小腿权重。
- 24 帧走路循环关键帧演示、播放、保存当前帧、过渡优化标记；底部时间轴支持点击帧格、输入帧号和拖动滑杆选择具体帧。
- 关键帧记录栏：时间轴上方常驻显示“已记录帧”列表，可直接看到保存过哪些帧，点击帧号可跳转；当前帧会标明已保存/未保存。
- 手动关键帧回放：保存姿态时记录真实 GLB 骨骼局部变换，播放时在相邻关键帧之间插值，人物模型会跟随保存的动作移动。
- 默认走路播放：没有关键帧时点击播放会自动生成走路关键帧，程序走路模板会直接驱动导入 GLB 的真实腿部/手臂骨骼，不只移动脚底接触标记。
- 动作模板方向：根据左右腿/手臂骨骼自动推导角色前方，脚底接触点和“前”方向箭头沿角色前方移动，不再写死世界 Z 轴；生成模板时会先把 T pose 手臂粗调放下。
- 权重点显示控制：权重粒子默认隐藏，只在权重笔刷模式且打开“显示权重点”时出现，避免干扰姿态和动作编辑。
- JSON 导出预览，后续可接入 GLB/动画导出。

## 后续 EXE 路线

功能确认后，把这个 Web demo 放进 Electron 壳即可打包 Windows EXE。骨骼/权重/动画数据结构应继续保持 JSON 可序列化，后续再接 glTF 导出。
